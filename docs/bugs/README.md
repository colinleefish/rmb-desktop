# Bug investigations

One investigation doc per bug: `B<nn>-investigation.md`, created from
`templates/bug-investigation.md` during phase 2 of the Bug workflow (AGENTS.md).

The path recorded in the `investigation` field of `bug_list.json` is authoritative —
entries backfilled before this convention existed may point elsewhere
(e.g. `docs/audit/2026-08-29-zcode-capture-bugs/INVESTIGATION.md`).
